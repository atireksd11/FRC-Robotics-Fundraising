# FRC Fundraising — Team 2935

Fundraising system for NACI Robotics, Team 2935 (North Albion Collegiate Institute, Rexdale, Toronto).

Target: raise **$40,000–50,000 CAD** for the season. Total season costs $78,800. First milestone: **$500–1,000 received**.

## How it works

```
Apollo (Muse pulls 25-50 contacts/day) ──┐
Google Maps / websites (main source) ─────┼─► Muse researches + drafts (per email-rules.md)
Boardy / warm intros ─────────────────────┘         │
                                                      ▼
                                            Atirek approves the day's batch
                                                      │
                                                      ▼
                                            Muse sends via Gmail + logs it
                                                      │
                                                      ▼
                                    Gmail + Cold Emailing tab (replies, follow-ups)
                                    Linear = tracker only (tasks, funnels, approvals)
```

One engine: **leads → research → personalized draft → Atirek approves exact text → send → track replies → follow up once after ~7 days → close.** Warm intros first. 50 emails/day each — Atirek + a friend from the robotics team, working together, 100/day total.

Once the team gets Apollo Pro, the work gets automated on Linear with ChatGPT and Muse just monitors.

## The five funnels

1. **Individual donations** — TDSB School Cash Online, tax receipts for pure donations.
2. **Low-ticket business sponsors ($100–1,000)** — the V1 priority.
3. **High-ticket corporate sponsors ($2,500–10,000+)** — after the basic system works.
4. **Grants + equipment** — Studica (open to Jan 31, 2027), Rotary Etobicoke (up to $5k).
5. **Business revenue partnerships** — parked until funnel 2 works. One test only, needs school approval.

## Files

- `email-rules.md` — the writing rules for every sponsor email. No dashes, no AI words, connection first.
- `chatgpt-context-pack.md` — upload this + `email-rules.md` to ChatGPT.
- `leads-template.csv` — columns for the lead list. **No real contact data in this repo** — live leads live in the Google Sheet only.

## Rules

- No email goes out without Atirek's approval of the exact text. Ever.
- Never invent team size, results, awards, sponsor names, or dollar amounts.
- Never promise a tax receipt for a sponsorship — receipts are only for pure donations.
- Money raised is the metric, not emails sent. Track $ promised, $ received, and in-kind separately.
